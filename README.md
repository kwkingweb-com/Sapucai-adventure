# Sapucaí Adventure Quadriciclos — versão visual V4

Site de apresentação em HTML5, CSS3 e JavaScript puro, sem frameworks, banco de dados ou PHP.

## Abrir no computador
1. Descompacte `sapucai-adventure-visual-v4.zip`.
2. Abra a pasta `sapucai-adventure-visual-v4` no VS Code e execute `index.html` com Live Server; ou abra `index.html` diretamente no navegador.
3. Todas as fotos, o logotipo e os estilos são **arquivos locais**; não precisam de conexão para aparecer. O WhatsApp, o Instagram e o Google Maps exigem internet.

## O que mudou
- Logo oficial fornecida pelo usuário incorporada no cabeçalho e no rodapé.
- Textos significativamente reduzidos e maior destaque às fotografias reais.
- Novo banner inicial, carrossel de 3 banners, foto-banner, roteiro em blocos curtos e galeria visual.
- Política de cancelamento preservada em tópicos expansíveis, com comunicado original ampliável.
- Formulário simplificado: nome, WhatsApp, data, participantes e observações. O envio abre o WhatsApp da empresa com a solicitação pronta, sem simular disponibilidade ou pagamento.

## Fotos
Arquivos em `img/` incluem 3 fotografias fornecidas na conversa, o comunicado de cancelamento e a logo fornecida pelo usuário. Algumas fotografias são reaproveitadas em composições diferentes, sem representar experiências ou locais não confirmados.

## Informações verificáveis
- Duração aproximada: 1h30.
- Passeio apreciativo com guia acompanhando todo o percurso.
- Paradas: cachoeira, primeiro e segundo balanços infinitos.
- Política: conforme comunicado fornecido; prazos intermediários devem ser confirmados com a equipe.
- WhatsApp: (35) 99905-0218.

A publicação comercial depende da confirmação dos dados, das regras e dos direitos de uso das fotos com a operação.
